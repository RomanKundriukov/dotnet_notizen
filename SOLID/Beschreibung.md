# SOLID-Prinzipien

Der Begriff **SOLID** ist ein Akronym für eine Reihe von Prinzipien zur Gestaltung von Programmcode und zum Aufbau flexibler und anpassbarer Software.

Der Begriff wurde von dem bekannten amerikanischen Softwareentwickler **Robert C. Martin** geprägt, der auch als **Uncle Bob** bekannt ist.

Das Akronym setzt sich aus den Anfangsbuchstaben der fünf SOLID-Prinzipien zusammen:

- **S** — Single Responsibility Principle — Prinzip der einzigen Verantwortlichkeit
    
- **O** — Open/Closed Principle — Open-Closed-Prinzip
    
- **L** — Liskov Substitution Principle — Liskovsches Substitutionsprinzip
    
- **I** — Interface Segregation Principle — Prinzip der Schnittstellentrennung
    
- **D** — Dependency Inversion Principle — Prinzip der Abhängigkeitsumkehr
    

> [!NOTE]  
> SOLID-Prinzipien sind keine Design Patterns und auch keine starren Regeln, die bei jeder Entwicklung zwingend angewendet werden müssen.  
> Ihre Anwendung kann jedoch den Code verbessern und spätere Änderungen sowie die Wartung vereinfachen.
